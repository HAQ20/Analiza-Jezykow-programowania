Python to wysokopoziomowy, interpretowany język programowania, ceniony za czytelną składnię i wszechstronność. Jest wykorzystywany m.in. w analizie danych, automatyzacji, tworzeniu aplikacji internetowych i uczeniu maszynowym.

Popularność:
Według danych projektu liczba nowych repozytoriów z Pythonem wzrosła z 377 w 2008 roku do 60 012 w 2025 roku — około 159 razy.

Skąd ta popularność?
Python oferuje rozbudowany ekosystem bibliotek, działa na wielu systemach i pozwala szybko tworzyć czytelne prototypy oraz gotowe rozwiązania.

Historia i rozwój:
język stworzył Guido van Rossum; jego pierwsza publiczna wersja ukazała się w 1991 roku. Python 3, wydany w 2008 roku, wprowadził istotne zmiany i stał się podstawą dalszego rozwoju języka. Python jest rozwijany w ramach regularnych wydań.

Najważniejsze zmiany w historii Pythona:
1991 — Python 0.9.0: pierwsze publiczne wydanie; zawierało m.in. funkcje, moduły i obsługę wyjątków.
2000 — Python 2.0: dodano m.in. list comprehensions, obsługę Unicode i mechanizm zbierania cyklicznych odwołań.
2008 — Python 3.0: duża zmiana niekompatybilna wstecz; tekst stał się domyślnie Unicode, print funkcją, a dzielenie liczb całkowitych zaczęło zwracać wynik ułamkowy.
2015 — Python 3.5: wprowadzono składnię async/await oraz wskazówki typów.
2016 — Python 3.6: dodano f-stringi ułatwiające formatowanie tekstu.
2020 — Python 3.9: dodano m.in. operator łączenia słowników |.
2021 — Python 3.10: pojawiło się dopasowywanie wzorców match/case.
2022 — Python 3.11: poprawiono wydajność oraz dodano grupy wyjątków i składnię except*.

Gdzie się go używa?
W nauce o danych i AI (m.in. NumPy, pandas, PyTorch), backendzie aplikacji (Django, Flask), skryptach automatyzujących pracę oraz edukacji.
